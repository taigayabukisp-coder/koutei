# koutei

バーチャート（ガントチャート）形式の工程表を作成するツールです。`index.html` をブラウザで開くだけで使えます。サーバーやインストールは不要です。

## 主な機能

- タスク名・開始日・作業日数・工種・色をチャート上で直接編集
- 日曜休工・土曜休工の切り替え（休工日を除いて終了日を計算）
- 「全体」表示と「月」表示の切り替え
- A4横・1か月1ページでの印刷
- テキスト出力・読み込み（LLMに修正を依頼して読み戻す用途を想定）

## データの保存

編集内容は使用中のブラウザ（`localStorage`）に自動保存され、再読み込みしても残ります。
保存先はそのブラウザの中だけなので、別のPCやブラウザとは共有されません。
他の環境へ移す場合やバックアップには「テキスト出力」で `.txt` を保存し、「テキスト読み込み」で読み込んでください。
